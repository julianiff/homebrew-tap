# julianiff/tap

Homebrew formulae for [teer](https://github.com/julianiff/teer), semantic code review in the terminal.

## Install

```sh
brew install julianiff/tap/teer
```

Homebrew taps this repository on first use. Update with `brew upgrade teer`.

## How it's maintained

`Formula/teer.rb` is written by teer's release workflow on every tagged release. It installs the prebuilt binaries from the [GitHub release](https://github.com/julianiff/teer/releases) (macOS and Linux, arm64 and x86_64). Please don't edit it by hand; report problems on [teer's issues](https://github.com/julianiff/teer/issues).
